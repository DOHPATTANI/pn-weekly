# แบบ พ.3-01 จาก Excel ฉบับผู้ใช้ 28/10/2569

Source: ตัวอย่างทะเบียนคุมทรัพย์สิน พ.3-01.xlsx ที่แนบในบทสนทนา ตรวจ OOXML sheet ตัวอย่าง ไม่รันสูตร/คำสั่งในไฟล์และไม่ใช้ข้อมูลตัวอย่างเป็นข้อมูลธุรกิจ

| ส่วน | ข้อมูลจากต้นแบบ | การนำไปใช้ |
|---|---|---|
| กระดาษ | A4 แนวนอน, margin ซ้าย/ขวา 0.3645833333 นิ้ว | margin default 35 CSS px |
| ตาราง | A:AH แบ่งเป็น 12 logical columns | สัดส่วน width จากผลรวม physical columns |
| เนื้อหา | หัวตาราง 46.5 pt, acquisition 96 pt, row 15 pt | คง 62/128/20 CSS px ใน renderers |
| metadata | column boundaries 0.2205/0.3308/0.624 และ location/company 0.4141 | shared p301MetadataFields สำหรับ vector และ workbook |
| ตัวอักษร | TH SarabunIT๙ 12 pt, heading 13.5 pt | ใช้ TH SarabunPSK ที่มีในระบบ 16/18 CSS px; ไม่อ้างว่าฟอนต์ตรงทุก pixel |
| ลายเซ็น | ช่องเว้นก่อนลายเซ็นและผู้ลงนามสองตำแหน่ง | คง signatureGap ที่ปรับได้และ pagination เดิม |

ไม่เปลี่ยนสูตรค่าเสื่อม วันเริ่มคิดค่าเสื่อม มูลค่ารวม ชื่อผู้รับจ้างจริง หรือสถานะตรวจยืนยัน ค่ารูปแบบที่เคยบันทึกเฉพาะกลุ่มงบยังคงใช้ได้ คืนค่าเริ่มต้นในตัวจัดการแบบฟอร์มเพื่อเลือก preset ล่าสุดและบันทึกเมื่อต้องการแทนค่าที่ปรับเอง

Acceptance: 12 columns, vector/XLSX ใช้สัดส่วนเดียวกัน, preview/export ใช้ live records, ไม่มีข้อมูลจาก workbook ถูกนำเข้าฐานข้อมูล, ทดสอบ pagination และจำนวนหน้าจริงก่อนยืนยันส่งมอบ
